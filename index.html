Miller

A simple notation for describing the orientation of planes inside a crystal.

Background

Why do we need a notation for planes?

A crystal is a repeating 3D lattice of atoms. Planes through those atoms have very different densities, spacings and properties, so we need a short, unambiguous name for each one.

History

Introduced by British mineralogist William Hallowes Miller in 1839 and still the standard in crystallography today.

Lattice basics

The unit cell is described by three axes (a, b, c) along x, y and z. In a cubic crystal, a = b = c.

The problem

Intercepts like "half, third, infinity" are awkward. Reciprocals turn them into clean whole numbers.

Concept

What are Miller indices?

A set of three integers that label a family of parallel crystal planes. They come from the plane's intercepts with the x, y and z axes.

( h  k  l )
  • h relates to the x-axis intercept
  • k relates to the y-axis intercept
  • l relates to the z-axis intercept

Why are they used?

  • To identify and name different planes in a crystal
  • To describe the orientation of crystal planes
  • To calculate interplanar spacing
  • To interpret X-ray diffraction (Bragg's law)
  • To study cleavage, slip and surface properties
Method

How to find Miller indices

Four steps. Each one feeds the next.

1

Find intercepts

Note where the plane cuts the x, y and z axes, in units of a, b, c.

e.g. 1, 2, ∞
2

Take reciprocals

Invert each intercept.

1, ½, 0
3

Clear fractions

Multiply by the smallest number that removes all fractions (the LCM of the denominators).

×2 → 2, 1, 0
4

Write (hkl)

Enclose the integers in parentheses, with no commas.

(210)
Important: a plane parallel to an axis never meets it, so its intercept is ∞ and the reciprocal is 0.

Application

Interplanar spacing

For a cubic crystal with lattice constant a, the distance between adjacent (hkl) planes is:

d = a / √(h² + k² + l²)
Planeh² + k² + l²d
(100)1a
(110)2a / √2 ≈ 0.707a
(111)3a / √3 ≈ 0.577a

This d is the same quantity used in Bragg's law, nλ = 2d sinθ, to analyse X-ray diffraction patterns.

Key points

Remember these rules

Brackets matter

(hkl) is a single plane, {hkl} is a family of equivalent planes, [uvw] is a direction. For example, {100} in a cube includes (100), (010) and (001).

Parallel axis

A plane parallel to an axis has an infinite intercept, which gives a zero index.

Negative index

A negative index is written with a bar over the number, for example (1 1 0) is read "one, bar one, zero".

Whole numbers

Always reduce to the smallest whole-number set. Parallel planes share the same indices, and larger indices mean planes packed more closely.

Conclusion

Summary

Miller indices give us a simple mathematical way to describe the orientation of planes inside a crystal.

Find the intercepts, take reciprocals, clear fractions, and write the result as (hkl).
